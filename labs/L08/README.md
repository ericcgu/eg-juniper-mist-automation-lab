# Lab 08 Resources

This directory contains resources for Lab 08: Managing Access Assurance.

## Required Files

### Certificates

The following certificate files are required for this lab:

1. **AJMA-CA_cert.crt** - AJMA Certificate Authority certificate
   - This file is read by the script to upload to the Mist organization
   - Place this file in the `labs/L08/` directory before running the lab

2. **Client Certificates** (for each wireless client 1-4):
   - `AJMA-wifi-1.crt` and `AJMA-wifi-1.pem`
   - `AJMA-wifi-2.crt` and `AJMA-wifi-2.pem`
   - `AJMA-wifi-3.crt` and `AJMA-wifi-3.pem`
   - `AJMA-wifi-4.crt` and `AJMA-wifi-4.pem` (intentionally invalid for testing)
   
   These files should be installed on the respective wireless client devices.

### Generated Files

The following files will be created by the lab script:

- **mist-ca.crt** - Mist organization CA certificate
  - Automatically downloaded from your Mist organization
  - Saved to `labs/L08/mist-ca.crt`

- **Country (C):** US
- **Location (L):** LAB
- **Organization (O):** AJMA
- **Common Name (CN):** 
  - CA: ajma-CA
  - Clients: ajma-wifi-1, ajma-wifi-2, ajma-wifi-3, ajma-wifi-4

### Private Key Password

The private key password for all client certificates is: **lab123**

### Testing Notes

- Clients 1, 2, and 3 have valid certificates and should authenticate successfully
- Client 4 has an intentionally invalid certificate to practice troubleshooting
- The NAC policy matches certificates with `*ajma*` in the Common Name (CN)

## Lab Environment

This lab assumes you have:
- A working Juniper Mist organization
- The Durham site configured
- Access Points deployed at the Durham site
- Wi-Fi client devices or containers for testing

## Troubleshooting

If you encounter certificate errors:
1. Verify all certificate files are in the correct location
2. Check that the AJMA-CA_cert.crt file is properly formatted (PEM format)
3. Ensure client certificates are installed on the test devices
4. Verify the private key password is correct (lab123)
5. Check the NAC policy is enabled and properly configured

For more information, refer to:
- `labs/08_Managing_Access_Assurance.py` - Main lab script
- Juniper Mist API Documentation
